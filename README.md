## 📖 Visão Geral

**FinanceQuest** é um jogo educativo gamificado que ensina literacy financeira para crianças, adolescentes e adultos de forma vivante e interativa. O jogo simula a vida real com desafios, eventos aleatórios e sistemas de recompensa.

### 🎯 Objetivos Principais
- 📚 Ensinar conceitos financeiros de forma divertida
- 🏆 Motivar através de gamificação (badges, níveis, ranking)
- 🌍 Criar uma comunidade global de aprendizes financeiros
- 💡 Preparar usuários para decisões financeiras reais

## 🚀 Features Principais

### 👨‍👧‍👦 Três Níveis de Dificuldade
- **Nível Kids (6-12 anos):** Conceitos básicos, linguagem simples
- **Nível Teens (13-18 anos):** Orçamento, crédito, investimentos iniciais
- **Nível Adults (18+):** Planejamento completo, aposentadoria, empreendedorismo

### 💰 Sistemas de Jogo
- Economia virtual com moeda própria
- Gerenciamento de receita e despesas
- Portfolio de investimentos interativo
- Sistema de missões progressivas
- Eventos aleatórios (promoções, emergências, mudanças de mercado)

### 🏅 Gamificação
- Sistema de pontos e experiência (XP)
- Badges e conquistas desbloqueáveis
- Ranking global entre jogadores
- Desafios mensais competitivos
- Certificados de conclusão

## 📦 Stack Tecnológico

### Frontend
- **React 18+** - UI interativa
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **Redux Toolkit** - State management
- **Recharts** - Visualização de dados financeiros

### Backend
- **Node.js + Express** - API REST
- **MongoDB** - Banco de dados
- **JWT** - Autenticação
- **Socket.io** - Multiplayer real-time

### DevOps
- **Docker** - Containerização
- **GitHub Actions** - CI/CD
- **Jest** - Testes automatizados

## 🛠️ Instalação

### Pré-requisitos
- Node.js 18+
- MongoDB 5.0+
- Docker (opcional)

### Setup Local

```bash
# Clone o repositório
git clone https://github.com/WAGNERASF/FinanceQuest.git
cd FinanceQuest

# Backend
cd backend
npm install
cp .env.example .env
npm run dev

# Frontend (em outro terminal)
cd frontend
npm install
npm start
```

### Com Docker
```bash
docker-compose up
```

## 🎮 Como Jogar

1. **Criar Conta** - Escolha seu nome e nível de dificuldade
2. **Escolher Profissão** - Selecione uma carreira com renda variável
3. **Gerenciar Finanças** - Cada mês, gerencie receitas e despesas
4. **Investir** - Escolha onde aplicar suas economias
5. **Completar Missões** - Alcance objetivos para ganhar XP e badges
6. **Competir** - Suba no ranking global
